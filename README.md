# HRBP 智能工作台

## 项目简介

本工作台源于真实的 **HRBP 实习业务场景**（招聘漏斗统计、候选人全生命周期管理、JD 画像拆解、团建活动运营、生日福利关怀），将原本分散在 Excel、招聘系统、IM 工具中的重复性工作，整合为一个可交互、可量化、可本地运行的 Web 应用。

**设计目标**：让一位 HRBP 在一个页面内完成「今日待办 → 候选人推进 → 漏斗复盘 → JD 初筛 → 活动福利」的全天候工作闭环。

---

## 核心特性

- 🚀 **零依赖、零构建**：单个 HTML 文件，双击即用，无需 Node / 服务器。
- 💾 **本地持久化**：候选人、待办、目标、工具收藏等自动存入 `localStorage`，刷新不丢；简历附件存入 `IndexedDB`。
- 🤖 **AI 辅助初筛**：内置简历解析、AI 匹配打分、面试问题推荐（接口预留，可对接 LLM）。
- 📊 **可视化招聘漏斗**：SVG 漏斗图 + 转化率、部门维度、时间趋势、HC 进度条。
- 🔍 **多维度筛选 & 排序**：候选人支持姓名/手机/邮箱/公司模糊搜索，按岗位、部门、状态、面试方式、电话沟通、面试结果组合筛选，表头一键排序。
- 📥📤 **批量导入 / 导出**：候选人支持 Excel 批量导入，全量数据一键导出 JSON / Excel。
- 📱 **响应式双端适配**：PC 端左侧功能栏，移动端底部 Tab Bar，自适应布局。
- 🎨 **语义化状态色**：面试结果、电话沟通、候选人状态等全部用颜色编码，一眼识别优先级。

## 功能模块

工作台共 **9 个功能面板**（另含移动端底部 Tab Bar 快捷入口），按左侧侧边栏分组：

### 🏠 主页（Dashboard）
- **实时问候 + 时钟 + 今日进度环**：显示当前时间、日期、今日已过百分比。
- **⚠️ 今日要处理**：自动聚合面试、生日、活动、逾期待办，分类型标签高亮（面试=紫 / 生日=粉 / 活动=青 / 逾期=红）。
- **🎯 今日工作目标**：可增删、勾选完成，支持回车快捷添加。
- **✅ 待办事项**：带完成态的 Todo List。
- **🛠 工具栏**：收藏常用网址或本地附件（拖拽 / 点击上传，单文件 ≤3MB，存于浏览器）。

### 👥 候选人管理（正式员工 / 实习生）
- 两张独立数据表，结构一致，分别管理社招/校招与实习生。
- **丰富筛选器**：岗位、状态、部门、面试方式（线上/线下）、电话沟通（已/未）、面试结果（通过/未通过/放弃/待定/待安排）。
- **表内联编辑**：状态下拉直接切换、面试官 Chips 选择、面试结果/电话沟通一键标色。
- **候选人详情抽屉**：时间线、面试记录、简历附件上传（拖拽区）、AI 匹配分。
- **批量导入**：`openImportCandidate` 解析 Excel 并映射字段。

### 📊 招聘漏斗（正式员工 / 实习生）
- **SVG 漏斗图**：简历量 → 面试量 → Offer → 入职，各阶段数值 + 转化率。
- **部门维度 & 日期区间筛选**，支持快捷时间范围。
- **趋势图**：按月统计各阶段变化（折线/柱状切换）。
- **HC 管理**：计划 HC、已招、待招、优先级（高/中/低）、进度条。
- **漏斗复盘报告**：自动生成 Markdown 报告，支持**复制 / 下载 .md / 打印 PDF**。

### 📄 JD 库（正式员工 / 实习生）
- 岗位 JD 录入、画像拆解（技能 / 经验 / 学历标签）、关联候选人简历匹配。
- 支持新增、编辑、删除岗位，状态管理。

### 🎁 活动 & 福利
- **🎉 团建活动**：活动物料清单（采购 / 到货 / 分发状态）、活动详情、复盘文档。
- **🎂 生日福利**：员工生日表、本月寿星高亮、福利方案下拉选择、福利计划可编辑文本框（自动保存）、按部门/月份筛选。

## 技术架构

| 层级 | 实现 |
|------|------|
| **视图层** | 原生 HTML + 语义化 `data-page-node-id` / `data-panel` 节点标记 |
| **样式** | 单文件 `<style>`，CSS 变量定义 12 色语义色板，Flex / Grid 布局 |
| **逻辑** | 原生 JavaScript（无框架依赖），模块化函数组织 |
| **可视化** | SVG 手绘漏斗图、ECharts-like 自绘趋势图（纯 JS） |
| **存储** | `localStorage`（结构化数据）+ `IndexedDB`（简历 / 附件二进制） |
| **构建** | 无构建步骤，WorkBuddy 资料库能力直接生成与部署 |

> 顶部注释明确标注：`本工作台通过 WorkBuddy 资料库能力（library skill）搭建、存储和部署`。

## 数据持久化

| 存储位置 | 内容 |
|----------|------|
| `localStorage` | 候选人、JD、活动、生日福利、待办、目标、工具收藏、漏斗筛选偏好 |
| `IndexedDB` | 候选人简历附件、活动物料附件等二进制文件 |

- 自动保存：表格内联编辑、生日福利方案、活动详情等改动即时落盘。
- 数据导入：`loadAllData()` 读取本地 JSON 恢复全量数据。
- 数据导出：`exportData()` 一键下载全量数据为 `.json`（顶部"导出数据"按钮）。

## 快速开始

1. **直接打开**
   ```bash
   # 双击文件，或用浏览器打开
   open hrbp_workspace_v32.html
   ```
   推荐使用 Chrome / Edge / Safari 最新版。

2. **首次使用**
   - 页面默认加载示例数据（如有），可清空后录入自己的数据。
   - 顶部"导出数据"按钮可随时备份。

3. **数据迁移**
   - 换设备时：先"导出数据"下载 JSON → 新设备打开页面 → 通过导入功能恢复。

> ⚠️ 所有数据保存在**当前浏览器的当前域名/文件上下文**中，清除浏览器数据会清空内容，请定期导出备份。

## 使用指南

### 添加候选人
1. 进入「正式员工 / 实习生」面板 → 点击 `+ 新增候选人`。
2. 填写姓名、岗位、部门、面试时间、方式等，保存即出现在表格。
3. 表格内**直接点击状态下拉**即可推进候选人（如 初筛→面试中→Offer→入职）。

### 推进招聘漏斗
1. 进入「招聘漏斗」面板，选择对应群体（正式/实习）。
2. 设置部门、时间区间，查看漏斗转化与趋势。
3. 点击"生成复盘报告"，可复制文本或下载 Markdown。

### 维护生日福利
1. 进入「生日福利」面板，导入员工生日表。
2. 系统自动高亮**今日寿星**，`福利方案` 列下拉选择，计划文本框自动保存。

## AI 能力说明

工作台内置以下 AI 辅助函数（**逻辑已集成，模型调用为可插拔预留**）：

| 函数 | 能力 |
|------|------|
| `extractResumeFromFile` | 从上传的简历文件提取结构化字段 |
| `parseResumeFields` | 解析简历文本 → 姓名/学校/经验等 |
| `aiEvaluateResume` | 简历与 JD 画像匹配打分（AI 匹配分列） |
| `rerunAIForCandidate` | 对单个候选人重新跑 AI 评估 |
| `copyQuestions` | 根据候选人 + JD 生成针对性面试问题 |

**接入真实 LLM 的方式**：在对应函数处替换为 OpenAI / 混元 / Claude 等 API 调用即可，输入输出 schema 已固化，无需改动 UI。

## 导出与分享

- **全量数据导出**：顶部按钮 → `exportData()` → 下载 `hrbp_data_YYYYMMDD.json`。
- **候选人批量导入**：面板内"批量导入" → 上传 Excel（`.xlsx`）→ 字段自动映射。
- **漏斗复盘报告**：
  - `copyFunnelReport()`：复制到剪贴板
  - `downloadFunnelReport()`：下载 `.md` 文件
  - `printFunnelReport()`：调用浏览器打印（可存为 PDF）

## 常见问题

**Q：数据会传到服务器吗？**
A：不会。全部数据存于本地浏览器（localStorage + IndexedDB），无后端、无网络请求（除可选 LLM 接入外）。

**Q：清空浏览器缓存后数据还在吗？**
A：不在。请务必通过"导出数据"定期备份 JSON。

**Q：为什么漏斗图数据没变化？**
A：检查是否已录入候选人且状态流转完整；可点击"刷新"按钮重算。

**Q：AI 评分显示为空？**
A：当前为预留接口，需自行接入 LLM API（见 [AI 能力说明](#ai-能力说明)）。

**Q：附件上传失败？**
A：单文件限制 ≤3MB，存于 IndexedDB，私有浏览模式可能受限。
